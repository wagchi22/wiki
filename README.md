# Wiki

Uma base de conhecimento técnica pessoal para documentar configurações, ajustes, procedimentos e soluções que quero manter acessíveis para consultas futuras.

## Conteúdo

O Wiki reúne principalmente:

- **Configurações** — ajustes de sistemas, dispositivos, ferramentas e ambientes.
- **Guias** — procedimentos de instalação, configuração e manutenção.
- **Referências** — comandos, soluções e informações técnicas para consultas rápidas.

A documentação é construída de forma incremental, conforme novas configurações, descobertas e necessidades surgem.
