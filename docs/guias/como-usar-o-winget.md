# Como usar o Winget

:::info Visão geral
Guia rápido de como usar o Winget.
:::

## Verificar

No PowerShell ou Prompt de Comando, liste as atualizações disponíveis:

```powershell
winget upgrade
```

## Atualizar

Para instalar todas as atualizações listadas:

```powershell
winget upgrade -r
```
