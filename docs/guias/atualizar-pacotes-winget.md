# Atualizar Pacotes usando o Winget

:::info Objetivo
Como atualizar pacotes no Windows usando o Winget.
:::

## Listar atualizações

Abra o Terminal como Administrador.

Para listar as atualizaçãoes disponíveis execute:

```
winget upgrade
```

## Instalar atualizações

Para atualizar tudo silenciosamente execute:

```
winget upgrade -r -h
```
