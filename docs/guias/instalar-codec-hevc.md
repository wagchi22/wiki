# Instalar Codec HEVC

:::info Objetivo
Permite usar o codec nativo do Windows sem necessitar usar um player externo
 de vídeo.
:::

## Instalar

Acesse [aqui](https://store.rg-adguard.net/).

Selecione `ProductID` e cole `9n4wgh0z6vhq` e pressione ✔ para procurar.

Selecione a opção desejada e clique com o botão direito em `Salvar link como...`.

Execute o arquivo .appx para instalar.
