# Softwares Úteis

:::info Objetivo
Lista de softwares que podem ser úteis.
:::

## Registro

- [Registry Finder](https://registry-finder.com/) Substituto melhorado do Regedit do Windows
- [Revo Registry Cleaner](https://www.revouninstaller.com/br/products/revo-registry-cleaner-free/) Opção segura para limpeza de registro

## Armazenamento

- [CrystalDiskInfo](https://crystalmark.info/en/software/crystaldiskinfo/) Informações detalhadas sobre o estado do HDD/SSD

## Desinstalação

- [Revo Uninstaller](https://www.revouninstaller.com/br/products/revo-uninstaller-free/) Substituto melhorado do Desinstalador do Windows
